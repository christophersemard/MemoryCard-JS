## Fonctionnalités

- retournement des cartes ;
- détection des paires ;
- détection de la victoire ;
- interface responsive ;
- ressources graphiques locales.

## Consulter localement

Ouvrir index.html ou servir le dossier avec un serveur statique :

    python -m http.server 8000

## Contexte

Mini-jeu de formation consacré au DOM, aux événements et à la logique JavaScript.
